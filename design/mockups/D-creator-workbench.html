# 用 WEditor 把 Markdown 变成公众号爆款
写作者最痛的不是码字，
是**发布前的排版**：
同一篇稿子要在三个平台
各调一遍样式。
## 三步完成一键换肤
1. 在左边写标准 Markdown；
2. 右侧切到目标平台 tab，
实时看版心变化；
3. 按 `⌘⇧C` 复制带样式 HTML，
粘贴即发布。
## 主题是怎么生效的
排版引擎只做一件事：
**遍历 DOM，注入行内样式**。
这样微信编辑器才不会把 class 吃掉：
```ts
export const THEMES = {
  wechat:  { fontSize: 15, color: '#3f3f3f' },
  xiaohongshu: { fontSize: 16, lineHeight: 1.9 },
  zhihu:   { fontSize: 16, color: '#1a1a1a' },
} as const

// 关键：全部转成 style="" 再进剪贴板
function inline(el: Element) { … }
```
> 好的排版是隐形的：
> 读者只觉得「这篇读起来舒服」。
> —— 一位被后台样式折磨过的编辑
